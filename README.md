# Cryptography

A collection of C programs implementing fundamental cryptographic algorithms as part of the **Cryptography Laboratory** coursework.

## Implemented Algorithms

| No. | Algorithm | Technique | Source File |
|-----|-----------|-----------|-------------|
| 1 | Caesar Cipher | Substitution | `caesar_cipher.c` |
| 2 | Hill Cipher | Substitution | `hill_cipher.c` |
| 3 | Playfair Cipher | Substitution | `playfair_cipher.c` |
| 4 | Polyalphabetic Cipher | Substitution | `polyalphabetic_cipher.c` |
| 5 | Monoalphabetic Cipher | Substitution | `monoalphabetic_cipher.c` |
| 6 | Rail Fence Cipher | Transposition | `rail_fence.c` |
| 7 | Double Columnar Cipher | Transposition | `double_columnar.c` |

## About

This repository contains implementations of classical encryption techniques using the **C programming language**.

The purpose of this laboratory is to understand the working principles of different cryptographic algorithms, including their encryption and decryption processes.
